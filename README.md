# 📊 Blinkit Sales & Outlet Analysis | Power BI

An interactive Power BI dashboard developed to analyze Blinkit sales performance, outlet characteristics, product distribution, ratings, and key business KPIs.

## 🎯 Objective

To transform sales and outlet data into an interactive Power BI dashboard and derive meaningful business insights using KPIs, data visualization, filtering, and comparative analysis.

## 📌 Key KPIs

- 💰 Total Sales: $1.20M
- 📊 Average Sales: $141
- 📦 Number of Items: 8,523
- ⭐ Average Rating: 3.9

## 📈 Key Analysis

- Sales performance by Outlet Establishment Year
- Sales comparison across Outlet Sizes
- Sales contribution by Outlet Location Type
- Outlet Type performance comparison
- Item distribution by Item Type
- Low Fat vs Regular Fat Content analysis
- Interactive filtering by Outlet Location Type, Outlet Size, and Item Type

## 🎓 Learning Project

This project was completed as a guided learning project with the help of a YouTube tutorial. The tutorial provided the initial guidance and dashboard structure, while working through the project helped develop practical skills in Power Query, DAX, KPI creation, interactive filtering, visualization, and dashboard design.

The project helped me understand the workflow of:

**Raw Data → Data Cleaning → Calculations → KPIs → Visualization → Business Insights**
